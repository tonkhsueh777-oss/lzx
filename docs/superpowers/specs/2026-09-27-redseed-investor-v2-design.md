# 红薏米 × 柚信使｜商业投资官网 V2 设计规格

日期：2026-09-27

## 1. 项目目标

将现有偏“IP作品展示 / 面向大众”的官网，重构为面向以下对象的商业投资与项目合作官网：

- 潜在投资方
- 战略合作伙伴
- 政企与文旅项目方
- 渠道方与平台方

网站首要任务不是展示“好看、好玩”，而是让访问者快速理解：

1. 公司是谁
2. 公司为什么具备可投资 / 可合作价值
3. AI 文创工业化能力如何形成效率优势
4. 公司已经沉淀哪些原创 IP 资产
5. IP 如何形成 G / B / C 多端商业化
6. 哪些项目与能力已经得到验证
7. 核心团队为什么具备执行能力
8. 可以采用哪些投资与合作方式

## 2. 内容边界

全部商业事实以《2026-红薏米&柚信使 介绍.docx》为依据。

V2 不自行增加以下未经材料支持的数据：

- 营收
- 利润
- 估值
- 市场份额
- 融资金额
- 投资回报率
- 未提供的客户数量或项目数量

后续如用户补充这些信息，再扩展投资数据模块。

## 3. 核心定位文案

主定位：

> AI 文创工业化平台

副定位：

> AI 技术 × 原创 IP 资产 × 两岸运营网络

核心说明：

> 以生成式 AI 为生产底座，以原创 IP 资产为核心，通过数字内容、文旅场景与实体文创形成完整商业闭环。

## 4. 信息架构

### 4.1 顶部导航

- 首页
- 投资逻辑
- AI 产能
- 商业模式
- IP 资产
- 项目验证
- 核心团队
- 投资合作

右侧主 CTA：`预约商务洽谈`

手机端改为折叠菜单。

### 4.2 Section 01 — Hero / Investment Story

目标：10 秒内让投资人看懂公司定位与三项核心资产。

内容：

- 主标题：AI 文创工业化平台
- 副标题：AI 技术 × 原创 IP 资产 × 两岸运营网络
- 核心说明：从创意、内容、互动，到文创产品与商业化落地的完整体系
- CTA：`查看投资逻辑` / `商务合作`

核心数据：

- 40+ 原创版权资产
- 300% AI 产能提升
- 3–4 人完成传统约 15 人团队项目工作量

视觉：

- 不使用大面积卡通人物做主视觉
- 采用深色商业科技背景
- 右侧使用“AI 生产中枢 / IP 资产网络 / 商业闭环”图形占位
- 可保留少量东方纹理和朱红 / 金色强调

### 4.3 Section 02 — 投资逻辑 / WHY US

四个核心投资逻辑：

1. AI 重构生产效率
2. 自有原创版权资产
3. G / B / C 多端商业化闭环
4. 两岸双主理人和资源协同

展示方式：

- 大标题 + 四个逻辑模块
- 每项强调“事实 + 商业意义”
- 不使用娱乐化角色插画

### 4.4 Section 03 — AI PRODUCTION ENGINE

定位：从“会用 AI 工具”升级为“拥有 AI 文创工业化生产能力”。

流程：

市场需求 → 创意策略 → 脚本与世界观 → 角色资产 → 场景 / 分镜 → AI 动画 / 视频 → 游戏 / 互动 → 实体产品 → 市场测试 → 持续迭代

强调信息：

- 多模型混合工程化调度
- AI + 人工精修品控
- 多项目并行
- IP 研发周期可由数月压缩至数天

模型品牌名称退到辅助信息，不作为主卖点。

### 4.5 Section 04 — BUSINESS MODEL

核心标题：`一套 IP，多条收入曲线`

展示三端市场：

- G 端：政务 / 文旅 / 城市文化 / 展馆园区 / 两岸交流项目
- B 端：品牌联名 / IP 授权 / 企业礼赠 / 新品共创
- C 端：文创商品 / 桌游 / 游戏 / 数字内容 / 潮流消费品

图形关系：

原创 IP 资产 → G / B / C → 项目 / 授权 / 消费收入 → IP 资产增值

### 4.6 Section 05 — IP ASSET PORTFOLIO

将原来的“IP 宇宙”改成“IP 资产组合”。

重点展示：

- 《嘉庆君游台湾》
- 武汉方言系列
- 《开漳圣王 陈元光》
- 《郑成功 潮武王》
- 《柚信使》民俗神格矩阵

每张资产卡不只放图片，而显示：

- IP 定位
- 已有内容 / 产品形态
- 已验证成果（仅材料中有的才写）
- 可延展商业方向

媒体仍使用占位符。

### 4.7 Section 06 — TRACTION & CASES

标题：`不只是概念，已经落地`

两类验证：

A. 政企 / 两岸项目经验
- 国台办
- 民革中央
- 全国台联等项目经验
- 台湾同胞闪聚武汉
- 海峡两岸姊妹湖产业协作年会
- 华灿两岸青年读书会

B. IP 商业化验证
- 《嘉庆君游台湾》：漫画 / AI 动漫 / 桌游 / 网页游戏
- 武汉方言系列：服饰 / 徽章 / 动漫 / 游戏，线下市集验证
- 茶礼、纸牌、数字互动等产品形态

视觉采用案例卡 + 项目成果摘要，图片使用占位符。

### 4.8 Section 07 — MANAGEMENT TEAM

标题：`核心管理团队`

薛颖穜：
- AI 文创导演 / IP 内容负责人
- 原创 IP 策划
- 内容导演
- AI 内容生产
- 两岸文化资源

查钢：
- 商业战略 / 项目运营负责人
- 项目顶层设计
- 政企资源
- 资源统筹
- 市场化运营

团队核心关系：

> 创意资产 × 商业资源

人物照片暂用占位符。

### 4.9 Section 08 — INVESTMENT & PARTNERSHIP

标题：`我们正在寻找长期合作伙伴`

四类合作：

1. 资本与项目投资：股权投资 / 专项项目联合孵化
2. IP 授权与项目共建：品牌联名 / 新品开发 / 礼赠采购
3. 文旅空间合作：文旅集团 / 园区 / 展馆 / 快闪门店
4. 平台与宣发合作：AI 算力 / 动漫短剧发行 / 新媒体流量

“获取项目资料”V2 仅做视觉按钮和锚点，不虚构下载文件；后续用户提供 BP / PDF 后再接下载。

## 5. 视觉系统

整体比 V1 更克制、更商务。

比例：

- 70% 企业 / 投资视觉
- 20% IP 视觉
- 10% AI 科技感

色彩：

- 主背景：墨黑 / 深蓝灰
- 内容背景：纯白或非常浅的冷灰
- 主强调：暗朱红
- 辅助强调：低饱和金色
- 科技线条：冷蓝灰

避免：

- 满屏角色
- 游戏 UI 感
- 大面积火焰与奇幻场景
- 过多“潮玩品牌”式圆角卡片
- 无商业意义的装饰数据

## 6. 响应式策略

Desktop：
- 1200–1440px 主容器
- Hero 双栏
- 商业模式 / 投资逻辑适合 3–4 列结构

Tablet：
- 2 列为主
- 数据模块保持清晰对齐

Mobile：
- 单列叙事
- Hero 首屏先显示公司定位、核心说明、数据
- 图表改为纵向流程
- IP 资产卡可横向滑动或单列
- 固定或明显的商务合作 CTA

## 7. 交互

- 顶部锚点平滑滚动
- 手机菜单
- 页面滚动 reveal 动画，控制在轻度商务风格
- 资产卡 hover / focus
- 不加入复杂视差或强动画
- 尊重 prefers-reduced-motion

## 8. V2 开发范围

修改现有静态 GitHub Pages 项目，不新增后端。

主要文件：

- index.html：重构信息架构和商业文案
- styles.css 与现有分片 CSS：重构视觉系统与响应式布局
- script.js：保留菜单 / reveal / 锚点，调整到 V2 结构

图片 / 视频继续使用占位符，后续再替换真实素材。

## 9. 验收标准

V2 首页必须满足：

1. 第一屏不再像潮玩 / 游戏品牌官网
2. 访问者 10 秒内能理解“公司 + 投资价值 + 商业化路径”
3. 清楚显示 AI 产能、IP 资产、G/B/C 商业模式、项目验证、团队与合作方式
4. 不出现材料未支持的营收 / 估值 / 回报等数据
5. PC / 平板 / 手机无横向溢出
6. GitHub Pages 可直接运行
7. 图片和影片占位符可后续独立替换，不破坏结构
