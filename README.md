# 红薏米 × 柚信使 响应式官网 V1

静态 HTML/CSS/JS，无需安装依赖。

## 本地打开
直接双击 `index.html` 即可浏览；如需完整本地服务器预览，可执行：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 素材替换
当前所有图片与影片均使用占位符。后续可把：
- HERO IMAGE PLACEHOLDER
- IMAGE PLACEHOLDER
- VIDEO PLACEHOLDER
- PRODUCT / PHOTO

逐一替换为正式素材。

## 响应式断点
- Desktop: > 1024px
- Tablet: 821–1024px
- Mobile: <= 820px
- Small mobile: <= 560px
